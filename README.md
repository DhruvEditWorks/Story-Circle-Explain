# DS Framework Studio

Interactive cinematic filmmaking education website built with React, Vite, Framer Motion, GSAP, and Three.js.

## Run in VS Code

Do not use **Go Live** on the source folder. This is a Vite React app and needs the Vite dev server.

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal.

## Use with VS Code Go Live

Use the static build instead:

```bash
npm install
npm run build
```

Then open the `dist` folder with **Go Live**.

## GitHub Upload

Upload the source files to GitHub. Do not upload `node_modules`.
